# TechNova

TechNova is a responsive technology institute website designed to present programs, curriculum, schedules, FAQs, and application information through an interactive front-end experience.

## Features

- Responsive website layout
- Interactive curriculum map
- Dynamic weekly schedule
- Program information dialogs
- Application flow
- FAQ section
- Mobile navigation
- Canvas API elements
- Interactive front-end components

## Built With

- HTML
- CSS
- JavaScript
- Canvas API

## Project Scope

This project is a front-end concept created for portfolio and demonstration purposes.

The application flow is a demo experience and is not connected to a production admissions or back-end system.

## Local regression checks

Install Node.js and Google Chrome, then run `npm ci` and `npm test`.
Playwright starts and stops a local static server automatically. The suite covers
320, 360, 390, 768, 1024, and 1440px widths; course mappings, modal names and
keyboard focus, schedule tabs, sample form submission, FAQ, mobile navigation,
console errors, and horizontal overflow. Full-page screenshots are written to
`test-results/` (ignored by Git).

These checks use desktop Chromium viewport emulation, not physical devices or
screen-reader testing. Google Fonts requires internet access.
